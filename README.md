## Frontend

Клиентская часть находится в папке `client/`:

- `index.html` — главная страница с заголовком, ФИО, группой, датой, описанием и списком.
- `about.html` — страница «Обо мне» с ФИО, группой и описанием.

---

## Backend

Серверная часть находится в папке `server/` и реализована на C# (.NET Console App).

Программа выводит приветствие, ФИО, группу, текущую дату и время,
а также предоставляет меню:

1. Показать ФИО
2. Показать группу
3. Показать дату
4. Выход

Запуск:

```bash
cd server
dotnet run
```
